function binarySearch(A, target) {
  let low = 0, high = A.length - 1;
  while (low <= high) {
    let mid = Math.floor((low + high) / 2);
    if (A[mid] === target) return mid;
    // narrow the search interval
  }
  return -1;
}

06 · Binary Search

Cut the search space in half.

Binary search is faster because it discards half of the remaining range after each comparison. It requires a sorted array.

LOW MID HIGH
Ready
LOW, MID and HIGH will update after every iteration.
Iterations0Comparisons: 0

Why sorted?

If the middle value is smaller than the target, every value to its left can be ignored. If it is larger, the right side can be ignored. Sorting gives the algorithm the information needed to discard half the range.

Complexity

Best case O(1), average and worst case O(log n), extra space O(1) for the iterative version.

07 · Algorithms & Complexity

Understand performance at a glance.

Big-O notation describes how the amount of work grows as the input becomes larger.

Quick rule

O(1) → jump directly. O(log n) → repeatedly reduce the problem. O(n) → potentially inspect every item.

Applications

Arrays appear in tables, sensor samples, image pixels, marks lists, buffers, and many other systems where indexed data is useful.

Core Pseudocode

LINEAR-SEARCH(A, target)
1. for i = 0 to n - 1
2.     compare A[i] with target
3.     if A[i] == target, return i
4. return NOT FOUND

BINARY-SEARCH(A, target)
1. low = 0, high = n - 1
2. while low <= high
3.     mid = floor((low + high) / 2)
4.     if A[mid] == target, return mid
5.     if A[mid] < target, low = mid + 1
6.     else high = mid - 1
7. return NOT FOUND
